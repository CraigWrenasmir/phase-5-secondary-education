Six simulated workshop sessions with the chosen Steve Hogan Australian voice, original slide content and films, optional narration captions, searchable slide navigation and brief activity pauses. All original source files are available through the resources page. Viewing notes identify unfinished source material.

This repository is the master copy. Pull with `git pull --rebase` and edit its current pages directly. Do not regenerate pages from older output folders or templates.

The player uses web-optimised local `media/session-N.mp4` files. Full-quality session and combined workshop downloads remain in the existing Professional Learning [GitHub Release](https://github.com/CraigWrenasmir/phase-5-professional-learning/releases/tag/workshops-v1).
